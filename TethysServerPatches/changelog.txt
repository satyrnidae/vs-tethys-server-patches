v1.3.8-pre.5
- Vanilla tweaks (new config section: VanillaTweaks)
  - Right-click pickup: right-click a dropped item entity to pick it up;
    shows an interaction tooltip when looking at a dropped item entity
    - replicates ClickToPick mod
    - toggleable via VanillaTweaks/RightClickPickup/Enabled, default true
    - VanillaTweaks/RightClickPickup/RequireEmptyHand: if true, block pickup
      when holding a different item; if false, allow pickup with any item
      held, default false
  - StackableTemporalGears moved from VanillaFixes to VanillaTweaks
    (config migration: move the key to the VanillaTweaks section)
- Useful Oils x Aldi's Classes compat
  - Tinkerer and Handwright class-efficient oil recipes for mechanical power
    blocks: angledgears (x2 output), spurgear (x2 output), woodentoggle,
    clutch, transmission - using half the oil of standard Useful Oils recipes
    and the reduced ingredient costs from Aldi's Classes
  - Tinkerer recipes active when Useful Oils is installed
  - Handwright recipes active when Useful Oils + Aldi's Classes are installed

v1.3.8-pre.4
- Vanilla fixes
  - Cap interaction help entry count to limit Cairo surface size and GPU upload
    stalls on systems without Resizable BAR (VanillaFixes/MaxInteractionHelpEntries,
    default 16, 0 = no limit)
- Clothier's Heirlooms patches
  - Fixed Harmony patches failing to load against Clothier's Heirlooms 1.1.x
    (assembly version mismatch: expected 1.0.0.0, actual is 0.0.0.0)
  - Fixed autoloom and autospinner "Metal parts (tinkerer)" recipe patches
    targeting wrong array index (/0/ instead of /3/)
  - Migrated spinner and loom attribute schema to match Immersive Fibercraft's
    spinningProps/weavingProps format (inputQuantity, outputType, outputQuantity)
    so items patched by either mod work with both
  - Flax fibers, flax twine, wool fibers, and wool twine patches now skip when
    Immersive Fibercraft is installed (those items are already handled by IF)
  - Added wool twine -> wool weaving recipes for all 16 wool colors
    (plain, black, blue, brown, gray, green, orange, pink, purple, red, white,
    yellow, darkblue, darkbrown, darkgreen, darkred)
